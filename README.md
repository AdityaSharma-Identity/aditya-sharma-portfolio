# Aditya Sharma — Portfolio Website

A responsive single-page portfolio built with HTML, CSS and JavaScript.

## Publish
This repository is configured for GitHub Pages through a workflow in `.github/workflows/pages.yml`. Commits to `main` trigger a deployment.

## Site content
- Sample 1 visual theme: lavender-white background, midnight-blue cards, charcoal typography and copper accents.
- Education and Professional Experience sections are intentionally omitted.
- Phone number is intentionally omitted. Email and LinkedIn links remain.
- No build command or package installation is required.

Deployment is automated from the main branch.
